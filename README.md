# DCA + 이동평균선 추가매수 백테스터

정기 적립매수(매일/매주/매달) + 이동평균선 하회 시 추가매수 전략을 시뮬레이션하는 React 앱입니다.

## 실행

```bash
npm install
npm run dev
```

`.env`나 API 키는 필요 없습니다. 가격/환율/심볼검색 데이터는 Yahoo Finance 비공식 API를 프록시로 거쳐
가져옵니다 — 브라우저에서 직접 호출하면 CORS로 막히기 때문입니다. 두 군데에 동일한 프록시가 있습니다:

- **로컬 개발**: `vite.config.js`의 dev 서버 프록시 (`npm run dev`로 켰을 때만 동작)
- **배포(Vercel)**: `api/yahoo/[symbol].js`, `api/symbol-search.js` 서버리스 함수 (Vercel에 그대로
  올리면 자동으로 인식됩니다. `vercel --prod` 또는 GitHub 연동 배포 둘 다 됩니다)

프론트엔드는 두 경우 모두 같은 경로(`/api/yahoo/...`, `/api/symbol-search`)를 호출하므로 코드 변경 없이
로컬/배포 환경을 오갈 수 있습니다.

## 종목 심볼

Yahoo Finance 표기를 그대로 씁니다: `QLD`, `AAPL` (미국), `005930.KS`(코스피)/`005930.KQ`(코스닥).
원화가 아닌 통화(대부분 USD)인 종목은 `KRW=X` 일별 환율로 자동 환산합니다.

## 전략 규칙 (가정)

- 기본 적립매수는 선택한 주기(매일/매주 첫 거래일/매달 첫 거래일)마다 실행됩니다.
- 이동평균선 추가매수는 **기본 적립매수와 같은 날짜**에서만 조건을 확인합니다 (매주 적립인데 이평선은 매일
  체크하는 식의 혼합은 지원하지 않습니다).
- 여러 규칙(예: 200일선, 600일선)은 각각 독립적으로 누적 적용됩니다 — 두 조건을 동시에 만족하면 둘 다 매수합니다.
- 이동평균선 계산에 필요한 과거 데이터가 부족하거나 종목 상장일이 시작일보다 늦으면, 시작일을 자동으로
  조정하고 화면에 경고로 표시합니다. QLD처럼 상장 이전 구간을 합성 데이터로 메우는 처리는 하지 않습니다.
- 배당재투자, 매매수수료, 환전 스프레드는 반영하지 않습니다. 해외주식 양도세 22%는 체크박스로 최종
  평가액에서만 근사 반영합니다 (매도 시점 실제 세법과 다를 수 있습니다).
- IRR은 XIRR(뉴턴-랩슨, 필요 시 이분법 폴백)로 계산합니다.

## 구조

- `src/lib/yahooApi.js` — 가격/환율 fetch
- `src/lib/backtest.js` — SMA, 적립 스케줄, 시뮬레이션, XIRR, 전략 비교
- `src/components/` — 입력 폼, 요약 카드, 비교 테이블, 차트
